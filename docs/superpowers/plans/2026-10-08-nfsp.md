# Neural Fictitious Self-Play Implementation Plan

**Goal:** NFSP (Heinrich & Silver 2016) for Kuhn and Leduc with a `paper` and a `dream` preset, fast enough for
3e6-iteration Leduc runs, and the report tables against both published curves.

**Architecture:** One new module, `headsup/algos/nfsp.py`: numpy networks with a hand-written backward pass (the torch
modules of the same architecture provide the initial weights and are the reference in the tests), index-based
memories, a solver that plays 128 tables in one vectorised pass over the compiled tree (`Tree` of
`headsup/algos/pdcfr.py`) and a CLI with checkpoints. `headsup/algos/leduc_report.py` gets three tables.

**Tech Stack:** Python 3.12, numpy, PyTorch (initialisation, checkpoints files, test references), pytest.

**Spec:** `docs/superpowers/specs/2026-10-08-nfsp-design.md`

## Review Focus

1. **Seat symmetry**: the reward of seat 1 is the negated utility; each seat's next state is its own next infoset, not
   the opponent's; the seat that did not make the last action still gets its terminal transition.
   Test: `test_every_transition_reaches_m_rl_for_both_seats`.
2. **Hand boundaries**: pending decisions must not leak into the next hand of a table; modes are redrawn exactly there.
   Tests: the same, and `test_mode_is_drawn_per_hand_and_seat_and_held`.
3. **Hand-written gradients**: the dueling head, the normalisation and the skip connections.
   Test: `test_updates_equal_torch_autograd` (one whole update against torch for both architectures).
4. **Stale forward caches**: Double DQN evaluates the online network at the next states before the pass whose
   activations the backward pass uses. Test: the same (`dream` case).
5. **Snapshots**: `state_dict()` copies; `load_state_dict()` copies; the random generator's state is part of it.
   Test: `test_checkpoint_continues_identically_and_shares_nothing`.

## Validation runs (task 10)

```bash
mkdir -p runs/leduc_nfsp
for s in 0 1 2; do
  for preset in paper dream; do
    CUDA_VISIBLE_DEVICES="" OMP_NUM_THREADS=1 nohup .venv/bin/python -m headsup.algos.nfsp --game leduc --preset $preset \
      --iterations 3000000 --seed $s --json runs/leduc_nfsp/leduc_${preset}_s$s.json \
      --checkpoint runs/leduc_nfsp/leduc_${preset}_s$s.pt > runs/leduc_nfsp/leduc_${preset}_s$s.log 2>&1 &
  done
done
.venv/bin/python -m headsup.algos.leduc_report
```

(`dream` needs 2 500 000 iterations for the DREAM curve's end at 3.2e8 nodes; 3 000 000 keeps both presets comparable
on the paper's axis. Kuhn: `--game kuhn`, file names `kuhn_${preset}_s$s`.)
